这是一个非常清晰的错误：**Java 后端打通了电话，但对面（区块链）没接。**

报错 `Failed to connect to /127.0.0.1:8545` 意味着你的  **Hardhat 区块链节点没有运行** 。

当你更换了文件夹或者重启了电脑/终端后，本地的区块链网络（Localhost Node）会自动关闭，你需要重新启动它。

请严格按照以下 **“复活四部曲”** 操作。**注意：因为重启了区块链，合约地址会变，必须重新部署和配置！**

### 第一步：启动区块链节点 (Terminal 1)

打开一个新的 Git Bash 窗口，进入你的新项目目录：

**Bash**

```
cd ServerCode/local-hardhat
npx hardhat node
```

* **保持这个窗口开着！** 不要关闭。
* 你会看到它开始打印 `Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545`。

### 第二步：重新部署合约 (Terminal 2)

**这是最关键的一步。** 本地链重启后，之前的数据都没了，必须重新部署。

打开第二个终端窗口：

**Bash**

```
cd ServerCode/local-hardhat

# 1. 部署合约
npx hardhat run scripts/deploy-cc.js --network localhost
# (记下这里输出的新的 Factory 地址！)

# 2. 移交权限 (必做，否则后端没法审批)
npx hardhat run scripts/transfer-factory-ownership.js --network localhost
```

### 第三步：更新 Java 配置 (非常容易忘)

因为重新部署了， **合约地址 99% 变了** 。你必须把新地址填回 Java 项目。

打开 `ServerCode/business-application-service/src/main/resources/application.properties`：

**Properties**

```
# 务必更新为刚才 deploy-cc.js 输出的新地址！
blockchain.contract.factory.address=0x... (填入新地址)
blockchain.contract.token.address=0x...   (填入新地址)
```

*保存文件。*

### 第四步：重启 Java 后端 (Terminal 3)

回到你报错的那个 Java 终端窗口：

1. **重新编译** (让新配置生效)：
   **Bash**

   ```
   mvn clean package -DskipTests
   ```
2. **启动** ：
   **Bash**

```
   ./launch.sh
```

**做完这四步，你的“调试模式”启动日志里就会显示 `>>> ✅ 连接成功!` 了。**
