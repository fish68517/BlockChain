这是一个非常典型的 **企业级前后端分离 + 区块链 + 业务流程引擎 (BPM)** 的混合架构项目。从老师给你的代码结构和 README 文件来看，这是一个功能相当完整的系统。

我为你详细分析了代码逻辑，并整理了保姆级的运行步骤。

### 第一部分：代码功能逻辑分析

这个项目被拆分为三个核心部分，它们通过网络相互协作：

#### 1. 流程引擎服务端 (ServerCode / JBPM Server)

* **核心作用：** 这是一个基于 **Red Hat jBPM** 的业务流程管理服务器。它的任务是**“管状态”**。
* **逻辑分析：**
  * **`business-central-kjar`** : 这里面包含 `.bpmn` 文件，也就是你在之前图片里看到的那个长长的流程图（提议 -> 估值 -> 修复 -> 拍卖）。它是整个系统的“大脑”，定义了业务该怎么流转。
  * **`business-application-service`** : 这是与“大脑”对话的接口。它暴露 REST API，让外部应用（比如客户端）可以启动一个流程、完成一个任务（比如“审批通过”）。
  * **数据存储** : 它连接 `cc_jbpm_db` 数据库，专门用来存流程走到哪一步了（Process Instance）。

#### 2. 客户端应用 (ClientCode / Security)

* **核心作用：** 这是用户（买家、卖家、修复师、管理员）实际操作的  **Web 平台** 。
* **架构分析：**
  * **后端 (Spring Boot)** : 也就是 `src/main/java` 里的代码。它不仅是一个简单的 Web 后端，它还是一个  **“中间人”** 。
  * 对内：它连接 `collectorcoin_db` 存储用户信息、角色、上传的文件。
  * 对外：它通过 HTTP 请求调用 **JBPM Server** 来推动流程。
  * 对链：它（可能）集成了 Web3j 或通过前端与区块链交互。
  * **前端 (React)** : 也就是 `src/main/js` 里的代码。这是一个单页应用 (SPA)，用户在这里注册、登录、上传古董照片、点击“出价”。
* **角色权限** : 代码在数据库初始化脚本里明确定义了 5 种角色：`OWNER` (持有者), `INVESTOR` (投资者), `RESTORER` (修复师), `BUYER` (买家), `ADMIN` (管理员)。

#### 3. 智能合约 (ClientCode/.../contracts_deployment)

* **核心作用：** 提供 Web3 基础设施.
* **逻辑分析：** 使用 **Hardhat** 框架。包含部署脚本 `deploy.js` 和合约测试代码。这部分负责在本地启动一个区块链节点，并将 ERC-1155 或相关合约部署上去。

### 第二部分：详细运行步骤指南

**注意：** 此项目对环境版本要求极其严格，尤其是  **Java 8** 。版本不对绝对跑不起来。

#### 步骤 0: 环境准备 (Prerequisites)

请确保你的电脑安装了以下软件，并配置了环境变量：

1. **Java JDK 8** : 必须是 Java 8。配置好 `JAVA_HOME`.
2. **Maven** : 用于构建 Java 项目 (`M2_HOME`).
3. **Node.js & NPM** : 用于构建前端和运行 Hardhat.
4. **MySQL 数据库** : 运行在默认端口 3306.

---

#### 步骤 1: 数据库初始化 (MySQL)

你需要创建**两个**独立的数据库，分别给 Server 和 Client 用。打开你的 MySQL 客户端（如 Workbench 或 Navicat），执行以下 SQL：

**1.1 创建 JBPM 流程引擎数据库**

**SQL**

```
CREATE DATABASE cc_jbpm_db;
CREATE USER 'ccjbpmusr'@'localhost' IDENTIFIED BY 'ccjbpmpass';
GRANT ALL PRIVILEGES ON cc_jbpm_db.* TO ccjbpmusr@localhost;
GRANT XA_RECOVER_ADMIN ON *.* TO 'ccjbpmusr'@'localhost'; -- 如果报错可忽略，但在Linux上可能需要
FLUSH PRIVILEGES;
```

**1.2 创建 客户端应用数据库**

**SQL**

```
CREATE DATABASE collectorcoin_db;
CREATE USER 'collectorcoinusr'@'localhost' IDENTIFIED BY 'collectorcoinpwd';
GRANT ALL PRIVILEGES ON collectorcoin_db.* TO collectorcoinusr@localhost;
FLUSH PRIVILEGES;

-- 预置角色数据 (必须执行，否则注册会失败)
USE collectorcoin_db;
CREATE TABLE IF NOT EXISTS roles (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(20)); -- 如果表没自动生成，可能需要先启动一次Client再执行插入
INSERT INTO roles (name) VALUES ('ROLE_OWNER'); 
INSERT INTO roles (name) VALUES ('ROLE_INVESTOR'); 
INSERT INTO roles (name) VALUES ('ROLE_RESTORER'); 
INSERT INTO roles (name) VALUES ('ROLE_BUYER'); 
INSERT INTO roles (name) VALUES ('ROLE_ADMIN');
```

---

#### 步骤 2: 启动区块链网络 (Hardhat)

为了让后端能连接到区块链，你需要先启动本地链。

1. 打开终端，进入目录：`CollectorCoin/ClientCode/tut-react-and-spring-data-rest-master/security/contracts_deployment`
2. 安装依赖：
   **Bash**

   ```
   npm install
   ```
3. 启动本地节点（不要关闭这个窗口）：
   **Bash**

   ```
   npx hardhat node
   ```
4. **（可选）部署合约** ：打开新终端窗口，在同一目录下运行：
   **Bash**

```
   npx hardhat run scripts/deploy.js --network localhost
```

   *记下部署生成的合约地址，后面可能要填到配置文件里。*

---

#### 步骤 3: 启动 JBPM 服务端 (Server)

这是流程引擎，必须先启动它。

1. 打开终端，进入目录：`CollectorCoin/ServerCode/business-application-service`
2. 编译项目：
   **Bash**

   ```
   mvn clean install
   ```
3. 启动服务 (Mac/Linux 使用 ./launch.sh, Windows 使用 launch.bat)：
   **Bash**

   ```
   # Mac/Linux:
   chmod +x launch.sh
   ./launch.sh clean install

   # Windows:
   launch.bat clean install
   ```
4. 等待启动完成，通常运行在 `http://localhost:8090`.

---

#### 步骤 4: 启动 客户端应用 (Client)

这是用户界面。

1. 进入目录：`CollectorCoin/ClientCode/tut-react-and-spring-data-rest-master/security`
2. **配置上传路径** ：

* 找到 `src/main/resources/application.properties.example`。
* 复制并重命名为 `application.properties`。
* 修改 `collectorcoin.app.absoluteUploadPath` 为你电脑上一个存在的文件夹路径（用来存上传的图片）。

1. 编译并运行：
   **Bash**

   ```
   mvn clean install
   mvn spring-boot:run
   如果找不到 maven指令使用 ：./mvnw spring-boot:run
   ```

   *(这一步会自动调用前端构建工具，如果报错，你可能需要先进入 `src/main/js` 手动运行 `npm install`)*
2. 等待启动完成。通常运行在 `http://localhost:8080`。

---

#### 步骤 5: 验证与使用

1. 打开浏览器访问客户端地址（通常是 `localhost:8080`）。
2. **注册用户** ：因为这是新库，没有用户。你需要点击 "Register" 注册一个 Owner（卖家）和一个 Admin（管理员）。
3. **开始流程** ：登录 Owner 账号，上传一个物品。
4. **查看后台** ：你可以观察 JBPM Server 的日志，看是否有流程启动的记录。

### 常见报错急救 (Troubleshooting)

* **端口占用** ：确保 8080 (Client), 8090 (Server), 3306 (MySQL), 8545 (Hardhat) 没被其他软件占用。
* **Java 版本错误** ：如果在编译时报一大堆类找不到的错误，99% 是因为你没用 Java 8。请检查 `java -version`。
* **数据库连接拒** ：检查 `application.properties` 里的数据库密码是否和你在步骤 1 里设置的一样。
