#### 3. jBPM 集成：Custom WorkItemHandler (Java)

这是 jBPM 和 区块链的连接桥梁。当流程走到“Mint NFT”节点时，这个类会被执行。

**Java**

```
import org.kie.api.runtime.process.WorkItem;
import org.kie.api.runtime.process.WorkItemHandler;
import org.kie.api.runtime.process.WorkItemManager;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Component;

@Component("MintNFTHandler") // 在 jBPM 部署描述符中注册这个名字
public class MintNFTWorkItemHandler implements WorkItemHandler {

    @Autowired
    private BlockchainService blockchainService;

    @Override
    public void executeWorkItem(WorkItem workItem, WorkItemManager manager) {
        try {
            // 1. 从流程变量中获取数据
            Integer assetId = (Integer) workItem.getParameter("AssetId");
            String ownerAddress = (String) workItem.getParameter("OwnerAddress");
        
            System.out.println("jBPM 触发上链: Asset ID " + assetId);

            // 2. 调用区块链服务
            String txHash = blockchainService.mintNFT(ownerAddress, assetId, "Initial_Valuation");

            // 3. 将结果写回流程变量 (供后续查看)
            Map<String, Object> results = new HashMap<>();
            results.put("TxHash", txHash);

            // 4. 通知 jBPM 任务完成，继续下一步
            manager.completeWorkItem(workItem.getId(), results);

        } catch (Exception e) {
            System.err.println("上链失败");
            manager.abortWorkItem(workItem.getId());
        }
    }

    @Override
    public void abortWorkItem(WorkItem workItem, WorkItemManager manager) {
        // 处理回滚逻辑
    }
}
```

### 1. 通俗类比：银行系统

为了让你彻底明白，我们用**“银行”**来做比喻：

* **Ganache = 银行的中央数据库系统**
  * 它是记账的地方。它记录了“谁有多少钱”、“这个古董现在属于谁”。
  * 如果没有 Ganache（也没有以太坊公网），就相当于 **银行没有了账本服务器** ，那钱和资产就没地方存了。
* **MetaMask = 你的银行卡 / 手机银行 App**
  * 它是用户用来操作账户的工具。你要转账，需要刷卡（签名）。
  * 客户说“不要 MetaMask”，意思是：**“用户觉得办卡、装 App 太麻烦了，别让他们自己操作。”**
* **你的 Java 后端 = 银行柜员**
  * 既然用户没有卡（MetaMask），那用户想转账怎么办？
  * 用户走到柜台（你的前端网页），告诉柜员（你的 Java 后端）：“我要转账”。
  * **柜员（Java）手里拿着万能钥匙，帮用户在系统（Ganache）里完成了转账。**

结论：

你可以为了用户体验砍掉“银行卡”（MetaMask），全部由柜员代办；但你不能砍掉“银行数据库”（Ganache），否则柜员也没法记账。

#### 为什么客户不想用 MetaMask？

* **标准 Web3 流程：** 网页弹出一个框 -> 用户输入密码 -> 用户点击“确认签名” -> 交易发送。

  * *体验：* 用户感觉不到区块链的存在，就像用淘宝一样顺滑。
