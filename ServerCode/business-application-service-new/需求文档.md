## 1. 项目概述

### 1.1 项目背景

CollectorCoin 是一个基于区块链技术的收藏品投资平台，将实体收藏品（如经典汽车）的修复项目代币化为动态NFT（dNFT），实现去中心化的投资、修复和拍卖全流程管理。

### 1.2 项目目标

- 实现收藏品项目的 NFT 代币化
- 构建完整的投资-修复-拍卖生命周期管理
- 通过 JBPM 工作流引擎实现业务流程自动化
- 通过智能合约保证交易的透明性和不可篡改性

### 1.3 技术栈

| 层级 | 技术选型 |
|------|----------|
| 后端语言 | Java (Spring Boot) |
| 工作流引擎 | JBPM |
| 区块链交互 | Web3j |
| 智能合约 | Solidity (ERC-1155) |
| 分布式存储 | IPFS |
| 数据库 | MySQL/PostgreSQL |

## 2. 功能需求

### 2.1 核心业务流程

```
项目创建 → 价值评估 → NFT铸造 → 众筹融资 → 分配修复者 → 修复完成 → 上架销售 → 拍卖成交 → NFT转移
```

### 2.2 功能模块划分

#### 模块一：JBPM 异步工作流

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 工作流节点调整 | 将 Bid Review 移至 Funding 之前 | 高 |
| 异步等待机制 | 使用 Human Task + TaskService API 替代 Signal Catch Events | 高 |
| 任务完成机制 | 通过 TaskService 编程式完成任务推进流程 | 高 |

**⚠️ 重要：Signal Catch Events 替代方案**

由于 JBPM Signal Catch Events 存在信号丢失、触发不稳定等问题，采用以下替代方案：

**方案：Human Task + TaskService API**

使用 Human Task 节点替代 Signal Catch Events，通过 `TaskService` 编程式完成任务：

```java
// 1. 查询等待中的任务
List<TaskSummary> tasks = taskService.getTasksAssignedAsPotentialOwner(
    "system", "en-UK");

// 2. 根据流程实例ID和任务名称筛选
TaskSummary targetTask = tasks.stream()
    .filter(t -> t.getProcessInstanceId().equals(processInstanceId))
    .filter(t -> t.getName().equals("WaitForNFTMinting"))
    .findFirst().orElse(null);

// 3. 认领并完成任务
if (targetTask != null) {
    taskService.claim(targetTask.getId(), "system");
    taskService.start(targetTask.getId(), "system");
    
    Map<String, Object> results = new HashMap<>();
    results.put("tokenId", tokenId);
    
    taskService.complete(targetTask.getId(), "system", results);
}
```

**需要创建的等待任务（Human Task）：**

| 任务名称 | 触发时机 | 输出参数 |
|----------|----------|----------|
| WaitForNFTMinting | 链上 DNFTCreated 事件 | tokenId |
| WaitForInvestmentConfirm | 链上 InvestorAdded 事件 | txHash |
| WaitForRestorationAssign | 链上 RestorerUpdated 事件 | restorer |
| WaitForRestorationComplete | 链上 RestorationCompleted 事件 | - |
| WaitForItemPost | 链上 ItemPosted 事件 | price |
| WaitForNFTTransfer | 链上 NFTTransferred 事件 | winner |

**方案优势：**
- ✅ 任务状态可查询，便于排查问题
- ✅ 可通过 REST API 或 TaskService 完成
- ✅ 支持超时处理和重试机制
- ✅ 任务完成有明确的事务边界

#### 模块三：Java 后端服务

| 服务名称 | 功能描述 | 优先级 |
|----------|----------|--------|
| BlockchainEventListenerService | 监听链上事件，通过 TaskService 完成对应的 Human Task | **最高** |
| InvestmentProxyService | 代理执行投资者的链上转账 | 高 |
| NFTMetadataService | 生成和更新 NFT 元数据 | 中 |
| IPFSService | 与 IPFS 交互，存取元数据 | 中 |
| BlockchainService | 区块链交互接口扩展 | 高 |

**BlockchainEventListenerService 核心实现：**

```java
@Service
public class BlockchainEventListenerService {
    
    @Autowired
    private Web3j web3j;
    
    @Autowired
    private TaskService taskService;
    
    @Autowired
    private ProjectListingRepository projectListingRepository;
    
    /**
     * 监听 DNFTCreated 事件，完成对应的等待任务
     */
    private void listenDNFTCreated() {
        web3j.ethLogFlowable(filter).subscribe(log -> {
            // 解析事件数据
            Long tokenId = extractTokenId(log);
            String projectAddress = extractProjectAddress(log);
            
            // 查找对应的流程实例
            ProjectListing listing = projectListingRepository
                .findByProjectAddress(projectAddress);
            Long processInstanceId = listing.getProcessId();
            
            // 完成等待任务（替代signal）
            completeWaitTask(processInstanceId, "WaitForNFTMinting", 
                Map.of("tokenId", tokenId));
        });
    }
    
    /**
     * 通用方法：完成指定的等待任务
     */
    private void completeWaitTask(Long processInstanceId, 
                                   String taskName, 
                                   Map<String, Object> results) {
        // 查询该流程实例的待办任务
        List<TaskSummary> tasks = taskService
            .getTasksByStatusByProcessInstanceId(
                processInstanceId, 
                Arrays.asList(Status.Ready, Status.Reserved),
                "en-UK");
        
        // 找到匹配的任务
        TaskSummary task = tasks.stream()
            .filter(t -> t.getName().equals(taskName))
            .findFirst()
            .orElseThrow(() -> new RuntimeException(
                "Task not found: " + taskName));
        
        // 认领、启动、完成任务
        taskService.claim(task.getId(), "system");
        taskService.start(task.getId(), "system");
        taskService.complete(task.getId(), "system", results);
        
        logger.info("Completed task {} for process {}", 
            taskName, processInstanceId);
    }
}
```

### 5.2 新增组件：Admin Backend Wallet 代理

**核心改动：在 Server Layer 新增 Web3j 服务**

```
原流程：前端 → MetaMask签名 → 链上
新流程：前端 → REST API → 后端Admin钱包签名 → 链上
```

**Admin Wallet 代理模式：**
```java
@Service
public class BlockchainProxyService {
    
    @Value("${admin.wallet.private-key}")
    private String adminPrivateKey;
    
    private Web3j web3j;
    private Credentials adminCredentials;
    
    @PostConstruct
    public void init() {
        web3j = Web3j.build(new HttpService(nodeUrl));
        adminCredentials = Credentials.create(adminPrivateKey);
    }
    
    /**
     * Admin钱包代理执行合约调用
     * Gas费由Admin钱包支付
     */
    public TransactionReceipt executeAsAdmin(Function function, 
                                              String contractAddress) {
        String encodedFunction = FunctionEncoder.encode(function);
        
        RawTransaction rawTx = RawTransaction.createTransaction(
            nonce, gasPrice, gasLimit, 
            contractAddress, encodedFunction);
        
        byte[] signedTx = TransactionEncoder.signMessage(
            rawTx, adminCredentials);
        
        return web3j.ethSendRawTransaction(
            Numeric.toHexString(signedTx))
            .send();
    }
}
```

## 9. 风险评估

| 风险 | 影响程度 | 缓解措施 |
|------|----------|----------|
| BPMN 修改破坏现有流程 | 极高 | 完整备份，测试环境验证，保留回滚方案 |
| 事件监听器失败 | 极高 | 心跳检测，自动重连，告警系统 |
| 异步状态不一致 | 极高 | 状态机管理，超时检测，手动干预接口 |
| Human Task 未找到 | 高 | 任务查询重试机制，延迟匹配，日志记录 |
| Gas 费过高 | 中 | 批量操作，使用测试网 |

**注：** 原方案使用 Signal Catch Events 存在信号丢失风险，已改用 Human Task + TaskService API 方案，该方案具有更好的可观测性和可靠性。
